# Code of Conduct

Neo Chat welcomes contributors with different backgrounds, languages, and
levels of experience. Keep collaboration respectful, focused, and safe.

## Expected behavior

- Be respectful and constructive in issues, pull requests, discussions, and
  review comments.
- Assume good intent and ask for clarification when something is unclear.
- Keep technical disagreements focused on evidence, tradeoffs, and project
  goals.
- Protect user privacy. Do not post API keys, access passwords, private chat
  logs, or other sensitive data.

## Unacceptable behavior

- Harassment, threats, insults, or discriminatory language.
- Sexualized language or unwanted personal attention.
- Publishing another person's private information without explicit permission.
- Repeatedly disrupting project spaces after maintainers request a change in
  behavior.

## Reporting

For conduct concerns involving private or sensitive information, open a
[private security advisory](https://github.com/u14app/neo-chat/security/advisories/new).
For other concerns, contact maintainers through the GitHub repository owner.
Maintainers may remove content, moderate participation, or block contributors
when needed to protect the community.

## Scope

This code applies to project repositories, issue trackers, pull requests,
community spaces, and public representation of Neo Chat.
