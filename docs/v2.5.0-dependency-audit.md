# v2.5.0 production dependency audit

Audit date: 2026-09-05  
Runtime: Node.js 24.18.0 and pnpm 10.30.3  
Command: `pnpm audit --prod --audit-level moderate`

The first audit reported 14 high, 11 moderate, and 2 low advisories. Those
counts described advisory entries in installed dependency chains; they did not
establish an equal number of exploitable Neo Chat vulnerabilities.

| Dependency chain                                              | Neo Chat reachability                                                                                 | Resolution                                                                  |
| ------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |

| `next > postcss > nanoid`                                     | PostCSS and Nano ID are used by the Next.js build and style toolchain.                                | Next.js now resolves PostCSS 8.5.23 and Nano ID 3.3.18.                     |
| `next > styled-jsx > @babel/core > browserslist`              | Browserslist is reachable during framework compilation.                                               | Pinned the compatible patched Browserslist 4.28.7 transitively.             |
| `mermaid > dompurify`                                         | Model or user Mermaid diagrams are sanitized in the browser before rendering.                         | Pinned the compatible patched DOMPurify 3.4.14 transitively.                |
| `ajv > fast-uri`                                              | AJV validates runtime schemas, including plugin and tool contracts.                                   | Pinned the compatible patched fast-uri 3.1.6 transitively.                  |

advisories. The overrides stay within each maintainer-declared compatible range
and are recorded in `pnpm-workspace.yaml`; `pnpm-lock.yaml` captures the resolved
tree.
